# Testing Skill

This skill provides testing guidelines.

## 1. Unit Tests
Ensure mocked boundaries.

## 2. Integration Tests
Ensure real DB or fake services are spun up.

## 3. Edge Cases
Check null, empty strings, max length, negative numbers, etc.

*This skill is strictly for testing/QA, not for feature implementation.*
