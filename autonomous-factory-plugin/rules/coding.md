# General Coding Standards

1. **Clarity over Cleverness**: Write code that is easy to read and understand.
2. **Modularization**: Keep functions small and focused on a single responsibility.
3. **Documentation**: All new and modified functions MUST have properly formatted docstrings or JSDoc comments explaining the purpose, parameters, and return types.
4. **DRY (Don't Repeat Yourself)**: Extract duplicated logic into reusable functions or components.
5. **Formatting**: Always format code using the project's standard formatter (e.g., Prettier, gofmt).
